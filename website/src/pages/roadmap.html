Roadmap

Where SnapForge is heading

Plans can change. Nothing below is a promise of a date; each step is reviewed and approved before it ships.

Now: SnapForge 1.0 release candidate — review and real-PC testing

SnapForge 1.0 (capture, scrolling capture, Editor, text extraction, Library, widget, drag-and-drop, screen recording and video editing) is complete as a release candidate and waiting for independent review, testing on physical Windows 11 PCs, code signing and a legal review. After approval, the first public release will be published on GitHub Releases and linked from the Download page.

Screen recording and video editing Release candidate

Included in the release candidate: recording, trimming and removing sections, saving frames as images and GIF export. Recording still needs testing with real sound devices, hardware video encoders, high-resolution displays, multiple monitors, sleep and lock before it can be approved.
