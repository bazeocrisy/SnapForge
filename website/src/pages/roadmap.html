Roadmap

Where SnapForge is heading

Release candidate 2 is in testing. Plans can change. Nothing below is a promise of a date; each step is reviewed and approved before it ships.

Now: SnapForge 1.0 release candidate 2 — testing Release candidate 2 (in testing)

SnapForge 1.0 (capture, scrolling capture, Editor, text extraction, Library, QuickDock, drag-and-drop, SnapForge Studio recording and video editing) is in its second release candidate, being tested by invited testers. Before a public release it still needs independent review, testing on physical Windows 11 PCs, code signing, a legal review and the owner's approval. After approval, the first public release will be published on GitHub Releases and linked from the Download page.

New in release candidate 2: an all-users installer (Program Files, one administrator approval), startup to the notification area and QuickDock only, the redesigned QuickDock and capture panel, SnapForge Studio with camera recording, and Library backups that include videos, the Trash and metadata. Details.

SnapForge Studio and video editing Release candidate 2 (in testing)

Included in the release candidate: recording the screen, the screen with the camera, or the camera only; trimming and removing sections, saving frames as images and GIF export. Recording still needs testing with real cameras, sound devices, hardware video encoders, high-resolution displays, multiple monitors, sleep and lock before it can be approved.

Names

“QuickDock” and “SnapForge Studio” are provisional names. They may change after a name and trademark check before the first public release.
