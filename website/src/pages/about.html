About SnapForge

An independent, open-source screenshot tool for Windows, built in the open.

The project

SnapForge is written in C# with .NET 10 and WPF for Windows 11 (x64) and uses only APIs that ship with Windows for capture, video and audio. Development happens in public on GitHub (external site), where every change is built and tested automatically on Windows before review.

Principles: free for everyone, local by default, no subscriptions, accounts, ads or telemetry, and honest status for every feature.

Video formats

Screen recording (part of the 1.0 release candidate) writes MP4 files using the H.264 and AAC encoders built into Windows; SnapForge does not include its own codecs. H.264 and AAC are patent-licensed formats; the licensing position for distributing an app that uses Windows' built-in encoders will be confirmed before screen recording is released.
