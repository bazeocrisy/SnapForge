Support and FAQ

SnapForge is a free, open-source project. Help is provided on GitHub on a best-effort basis.

Report a bug or suggest a feature

Open an issue on GitHub Issues (external site) (a free GitHub account is needed). Please include:

  • The SnapForge version and commit from Help → About.
  • Your Windows version (Settings → System → About) and your display setup (number of monitors, scaling).
  • What you did, what you expected and what happened instead.
  • Error logs from %LOCALAPPDATA%\SnapForge\logs if there are any (they contain text, never images).

Check before you attach. Issues are public. Do not attach screenshots or recordings that show private information — redact images first, and remember that videos cannot be redacted.

Frequently asked questions

Is SnapForge really free?

Yes. It is open source under the MIT License, with no subscriptions, paid tiers, accounts or ads. Donations are optional and never unlock features.

When can I download it?

When the first release has been reviewed and approved. The Download page will show it, with its checksum.

Does SnapForge upload my screenshots or collect data?

No. The app has no network code: no uploads, sync, accounts, update checks or telemetry. Captures are stored on your PC. See Privacy.

Are my captures encrypted?

No. SnapForge stores them as files in your Windows profile, protected by your Windows account. Turn on Windows device encryption or BitLocker to protect the disk.

Can someone undo a redaction in an image I sent?

Exported, copied and dragged images contain only the black box, so the hidden pixels are not in the file. Your own Library copy keeps the original until you choose Sanitize. See how redaction works.

Can I redact a video?

No. Anything visible or audible while recording is in the video. Check your screen before recording.

Why does Windows warn me before running it?

Development builds are not code-signed, so SmartScreen may show a warning. Only run a copy you downloaded from this site or the project's GitHub Releases whose checksum matches. See Windows security prompts.

Does it work on Windows 10, Mac or phones?

SnapForge supports Windows 11 (x64) only. Windows 10, Windows on Arm, Mac and phones are not supported, and no Mac or phone version is planned.

Print Screen opens the Windows Snipping Tool instead.

Windows can reserve Print Screen for the Snipping Tool. Turn off Use the Print screen key to open screen capture in Windows Settings → Accessibility → Keyboard, or choose another hotkey in SnapForge's Settings. SnapForge reports hotkeys it cannot register.

I can't find the widget.

Choose View → Show capture widget in SnapForge; it moves the widget to the top centre of the screen and opens it briefly.

How do I remove SnapForge completely?

See Uninstalling.
