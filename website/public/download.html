No public release yet

SnapForge has not had an approved public release. Development builds are reviewed and tested before a release is published, and the download button on this site stays disabled until the owner approves a GitHub Release.

The download will appear here, with its version, date, size, SHA-256 checksum and signing status, as soon as a release is published. Builds produced by automated tests are not offered here: they are temporary, unreviewed and expire.

Follow the project on GitHub (external site)

System requirements

  • Windows 11, 64-bit (x64) — the supported target (version 24H2 or later).
  • Windows 11 on Arm runs the x64 build through Windows' built-in emulation; this is not tested yet.
  • Windows 10 is not a supported target (Microsoft ended Windows 10 support on 14 October 2025). Screenshot features may work there but are not tested.
  • No .NET installation and no administrator rights are needed; the app is self-contained.
  • Screen recording (experimental) uses Media Foundation, which is part of normal Windows editions. Windows “N” editions need Microsoft's Media Feature Pack.

Installing

SnapForge is planned to ship as a portable ZIP: nothing is installed system-wide.

  1. Download the ZIP with the button above.
  2. Check its SHA-256 checksum against the one shown above.
  3. Right-click the ZIP, choose Extract All…, and pick a folder you own, for example Documents\SnapForge.
  4. Open the folder and run SnapForge.exe. Keep the other files in the folder next to it.

An installer is not available. If one is published later it will be listed here with its own checksum.

Verifying the download

Compare the file's SHA-256 checksum with the one on this page and on the GitHub release before you run it. In PowerShell, in the folder containing the download:

Get-FileHash .\SnapForge-<version>-win-x64.zip -Algorithm SHA256

The Hash it prints must match exactly (letter case does not matter). Each release ZIP also contains SHA256SUMS.txt listing the checksum of every file inside it.

Windows security prompts

Development builds of SnapForge are not code-signed. Windows SmartScreen may therefore say that it “prevented an unrecognized app from starting”. Each release states its signing status above.

  • Only run SnapForge if you downloaded it from this site or the project's GitHub Releases page and the checksum matches.
  • Keep Microsoft Defender and SmartScreen turned on. If Defender reports the file, do not run it — please report it instead.

Uninstalling

  1. If you turned on Launch SnapForge when I sign in to Windows, turn it off in SnapForge's Settings (or in Windows Settings → Apps → Startup).
  2. Exit SnapForge from its notification-area icon.
  3. Delete the folder you extracted it to.
  4. To remove your captures and settings as well, delete %LOCALAPPDATA%\SnapForge (paste it into the File Explorer address bar). If you moved the Library to another folder, delete that folder too. This permanently deletes your captures.

Source code and development builds

The source code, documentation and development history are on GitHub (external site). Developers can build SnapForge themselves with the .NET 10 SDK; the repository's README explains how.
