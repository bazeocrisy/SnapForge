Features

Everything between the screenshot and the send button

SnapForge 1.0 is a release candidate under review: nothing is in a public release yet. Screenshots are full-size images from the release-candidate build, taken automatically on a Windows test machine with fictional demo data. Select a screenshot to open it at full resolution.

Capture Release candidate

  • Region (it can span monitors), window, active window, a single display or the full screen
  • Magnifier with pixel position and colour; arrow keys move the selection by one pixel
  • The screen freezes while you select, so menus and tooltips stay put
  • Repeat the last capture, or start from an image on the clipboard
  • Multi-monitor and mixed-DPI aware; delay countdown; mouse pointer on or off
  • Presets with their own global hotkeys; Print Screen by default (configurable, conflicts reported)

Scrolling capture and text extraction Release candidate

  • Capture a long page or list: select the scrolling area, then let SnapForge scroll or scroll yourself
  • Frames are joined only where they match exactly; sticky headers and footers appear once. If an app redraws while scrolling, SnapForge stops instead of guessing
  • Extract text from any capture with the text recognition built into Windows — offline, nothing uploaded
  • Review and edit the recognised text, then copy it; the text is not saved

Text recognition uses the OCR languages installed in Windows; accuracy depends on the image.

Annotate and edit Release candidate

  • Arrow, line, rectangle, ellipse, highlight, text, numbered steps, pen, callouts and stamps
  • Blur and pixelate areas; crop, rotate, flip, resize, canvas size, border, drop shadow and watermark
  • Quick Styles; select, move, recolour, copy, paste and duplicate annotations at any time
  • Undo and redo for every edit; light, dark and high-contrast themes
  • Save as PNG, JPEG, BMP or TIFF, copy to the clipboard, or print

Redaction Release candidate

The Redact tool replaces the selected pixels with solid black and covers any annotations underneath. It does not blur or pixelate, so there is nothing to un-blur.

  • Exported, copied and dragged images are flattened: they contain only the black box, with no hidden layer and no metadata.
  • Your editable Library copy keeps the original pixels so you can still undo a redaction later. The Editor says so in a banner. Use Sanitize to remove the originals permanently.
  • Blur and pixelate are not redaction — use Redact for anything secret.
  • Redaction covers images only. Videos cannot be redacted.

Black boxes hide what is under them in the image itself; they cannot remove information that is visible elsewhere, such as in a file name you type or text outside the box.

Library Release candidate

  • Every capture is saved automatically and stays editable (or turn the Library off)
  • All, Recent, Favourites, Videos, Tags, Folders and Trash; search, sort and date groups
  • Rename, duplicate, export several at once, combine images, sanitize
  • Import PNG, JPEG, BMP and MP4 files
  • Backup and restore, retention rules, storage usage, movable location
  • Recent captures tray in the Editor: pin, reorder, persists across restarts

The Library is stored in your Windows profile and is not encrypted by SnapForge; Windows device encryption or BitLocker protects it.

Desktop widget Release candidate

  • A small tab at the top of the screen; hover or click to open it
  • Capture, Record, Editor, Library and your presets in one place
  • Drag it to the top, left or right edge of any monitor; it remembers where
  • Never takes keyboard focus from the app you are working in and hides itself during capture
  • Optional auto-hide and launch with Windows

Drag and drop Release candidate

  • Drag from the Editor's Drag button, the recent captures tray or the Library — one capture or several, images or videos
  • Arrives as an ordinary PNG (or JPEG) or MP4 file named after the capture and the time
  • Only flattened, redacted images without metadata ever leave SnapForge
  • Temporary copies are made only when the other app asks for them; cancelled drags leave nothing, and copies kept for slow uploads can be deleted in Settings at any time
  • Drop PNG, JPEG, BMP or MP4 files onto SnapForge to import them

Tested automatically with Windows drag-and-drop. Compatibility with specific apps (File Explorer, browsers, Office, Teams) is still being checked on real PCs.

Screen recording Release candidate

Real-PC testing pending. Recording has been tested automatically on a cloud Windows machine without sound devices or a graphics card. Sound, graphics-card encoders and high resolutions still need checking on real PCs.

  • Video mode in the capture panel and a Record button on the widget
  • Region, window or display to MP4 (H.264 video, AAC audio) using the encoders built into Windows
  • 30 FPS by default, 60 optional; Standard and High quality
  • System sound on and microphone off by default, switchable while recording with level meters
  • Floating toolbar with elapsed time, Pause/Resume, Stop and Cancel; the toolbar and outline are kept out of the video
  • Countdown, cursor on or off, hotkeys Shift+F9 and Shift+F10
  • Recordings interrupted by a crash are recovered at the next start (the last second or two can be lost)

Windows shows its own capture border while recording, and its microphone indicator while the microphone is on. Videos cannot be redacted.

Video editing Release candidate

  • Trim the start and end, and remove sections from the middle
  • Step frame by frame and save any frame to the Library as an image
  • Save the edited video to the Library or export it as MP4
  • Export an animated GIF with your choice of frame rate, width and looping
  • Play videos in the built-in player

Edited videos are re-encoded. GIFs have at most 256 colours and no sound.

Private by design

  • No network code: no uploads, sync, accounts, update checks or telemetry
  • No administrator rights needed — the installer installs for your Windows account only
  • Captures stay in your Windows profile (or a folder you choose)
  • Global hotkeys use the standard Windows mechanism — no keyboard hooks
