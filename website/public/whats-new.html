What's New

Development notes

SnapForge has no public release yet. Release notes will appear here when one is published; until then, this page summarises what has been built and where it stands. Release candidate 2 is in testing.

  1. SnapForge 1.0 release candidate 2 (1.0.0-rc.2) Release candidate 2 (in testing)

    November 2026 · in testing with invited testers · not a public release

    • SnapForge Studio (provisional name) for recording, with three modes: screen only, screen + camera, and camera only. Camera and microphone are off by default; the camera picture stays on your PC and Windows shows its camera indicator while it is on.
    • QuickDock (provisional name): the desktop widget has a new, original design — a compact rounded bar with the orange aperture mark and a horizontal row of actions.
    • A new capture panel design without the large capture button.
    • When SnapForge starts with Windows it opens only the notification-area icon and QuickDock.
    • The installer now installs for all users into Program Files and asks for administrator approval (UAC) once for install and uninstall; the app itself still runs without administrator rights. The portable ZIP is unchanged and needs no administrator rights. Uninstalling keeps your captures.
    • Library backups now include videos, the Trash and all metadata.
    • Packages are still not code-signed. Test builds are available to invited testers from the CI run page — see Test builds.

    Screenshots on this site still show the release-candidate 1 design where marked.

  2. SnapForge 1.0 release candidate 1 (1.0.0-rc.1) Release candidate

    November 2026 · superseded by release candidate 2 · not a public release

    • Scrolling capture, active-window capture, repeat last capture, new from clipboard, a selection magnifier.
    • Extract text from captures with the offline text recognition built into Windows.
    • New annotation tools: pen, callouts, stamps, blur and pixelate; rotate, flip, resize, canvas size, borders, drop shadows and watermarks; copy and paste annotations; print; BMP and TIFF export.
    • Video editing: trim, remove sections, save frames, export MP4 and animated GIF; import MP4 files.
    • Combine images, a first-start welcome, reset preferences, a new app icon and version details in About.
    • A per-user installer (no administrator rights; replaced by an all-users installer in release candidate 2) alongside the portable ZIP, with checksums and a software bill of materials. Packages are not yet code-signed.

  3. Screen recording Included in the release candidate

    November 2026

    • Video mode in the capture panel and a Record button on the widget.
    • Region, window or display to MP4 (H.264 + AAC) with system sound and microphone.
    • Floating toolbar, excluded from the recording; pause, resume, stop, cancel; hotkeys.
    • Crash recovery for interrupted recordings; videos in the Library with a player.
    • Automated tests on a cloud Windows machine: sound/picture sync, pause and resume, crash recovery and long recordings (up to two hours at 1080p). Tests on real PCs with sound devices and graphics cards are still to be done.

  4. Capture workflow, widget and drag-and-drop Development build

    November 2026 · awaiting independent review

    • New compact capture panel with presets and their own hotkeys.
    • Desktop widget that docks to the top, left or right edge of any monitor.
    • Native drag-and-drop of flattened images from the Editor, the recent captures tray and the Library; import by dropping image files onto SnapForge.
    • Optional launch with Windows, background Library loading, high-contrast theme support.

  5. Editor and Library Development build

    November 2026

    • Capture of regions, windows, displays and the full screen across monitors.
    • Annotations, Quick Styles, crop, undo/redo, black-box redaction.
    • An editable local Library with tags, folders, favourites, search, Trash and backup.
