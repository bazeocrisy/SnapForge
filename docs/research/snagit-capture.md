## 1. Capture modes and selection types

### Capture modes
- Windows Snagit has three capture modes (tabs): **All-in-One, Image, Video**. [S-CAP-02, S-CAP-01] DOC
- All-in-One: "Quickly capture an image, video, or scrolling capture with basic capture settings." [S-CAP-02] DOC
- All-in-One selections: "Region: click and drag crosshairs on the screen to manually select the area to capture. Window (Windows only): capture a specific window. Fullscreen: capture your entire display." [S-CAP-02] DOC
- Image: "Customize the settings to take a screenshot. Automatically add effects, share directly to a destination, and more." [S-CAP-02] DOC
- Video: "Customize the settings to record video. Set up audio, webcam options, and cursor effects." [S-CAP-02] DOC
- All-in-One flow: "The orange crosshairs appear. Click and drag to select the desired area to capture." The All-in-One toolbar then appears. Width and Height fields accept exact pixel dimensions. [S-CAP-02/S-CAP-26] DOC
- Window capture: "Move the cursor over the window to capture. When an orange dashed border appears around the window, click to select the highlighted area." [S-CAP-03/S-CAP-04] DOC
- 2026.0.0 introduced "simplified crosshairs when selecting an area to capture". The webcam is on by default the first time the user selects video mode. [S-CAP-22] DOC (from the Deployment Tool Guide extract)

### Image tab Selection dropdown
- Options per extracts: **Region, Window, Fullscreen, Fixed Region, Multiple Area (under "Advanced"), Menu, Scrolling, Clipboard**, plus File as a non-drag input. [S-CAP-03, S-CAP-29, S-CAP-27] DOC (assembled from several extracts; the exact current list is UNVERIFIED)
- "Clipboard, Fullscreen, Menu, and File" do not require dragging out an area. [S-CAP-03] DOC
- Fixed Region: select Region, click the **Selection Properties** button, then choose "Fixed region". You can set a pixel width and height. A **Set position** option pins the box to coordinates; with it off, the fixed box can be placed anywhere. [S-CAP-03, S-CAP-29 (2021.4)] DOC. Whether this path is unchanged in 2026 is UNVERIFIED.
- Multiple Area: "Advanced > Multiple Area" captures several windows or regions in one image. You hover to pick windows and click-drag to add regions. [S-CAP-03] DOC
- Menu: captures dropdown or cascading menus, usually combined with Time Delay. [S-CAP-03, S-CAP-20] DOC
- Object capture: appears only in Snagit 10/11 help, not in current pages. [S-CAP-32] DOC (historical). Its absence from current Snagit is INFER.
- Printer capture: Snagit installs as a printer. The "Snagit Printer" option captures the current document and opens it in Editor. [S-CAP-06 / search extract on reset/printer] DOC. Whether this is still present in 2026 is UNVERIFIED (Snagit 10/11 also listed Text and Web capture types, which no longer appear).

### Capture window toggles and dropdowns
- **Preview in Editor**: "Open the capture in Snagit Editor to preview, edit, and share the image or video. Disable this option if you do not want Editor to open automatically after the capture." [S-CAP-04/S-CAP-02] DOC
- **Copy to Clipboard**: "Automatically copy the capture to the clipboard to paste into another program or location." The documented editor-free workflow is to disable Preview in Editor and enable Copy to Clipboard. [S-CAP-04] DOC
- **Capture Cursor**: "Include the cursor in the capture. For image captures, the cursor is captured as a vector image that can be moved, edited, or deleted from the image." [S-CAP-03/S-CAP-04] DOC. The cursor is a separate editable object, not merged pixels.
- **Time Delay**: "Delay the start of the capture by a number of seconds to allow for additional setup time before capture for items such as dropdown menus. After clicking the Capture button, a countdown appears on the bottom-right corner of the screen." [S-CAP-03] DOC
- **Interval** (time-lapse, part of the Time Delay options): "Set an interval of time where Snagit continuously captures images of the selected area on the screen." It can "discard identical captures if nothing on the screen has changed." [S-CAP-03 / help PDFs] DOC. In 2026.3.1 the minimum interval went from 1 s to 3 s. [S-CAP-10] DOC
- **Share dropdown**: "If the Preview in Editor option is enabled, you must click the Finish button in Snagit Editor to share the capture. If the Preview in Editor option is disabled, the capture is sent to the selected destination." "Only destinations that support image file formats are available in the Image tab." [S-CAP-04] DOC
- Saving to file: set Share to **File**, use the gear icon to choose format and folder, and turn off Preview in Editor. [support article "Automatically Save Images to a Specific Format During Capture", https://support.techsmith.com/hc/en-us/articles/203731148, search extract] DOC
- **Effects dropdown**: listed next to Selection and Share in the 2022 help settings table, but the extract has no description. [S-CAP-28] DOC (existence only). Effects content is UNVERIFIED (Snagit 11 examples were Grayscale and Scale 50%).
- **Video tab "Open In"** setting replaces the Preview in Editor toggle for video, from 2026.1.0 onward. [S-CAP-10/S-CAP-22 via extract] DOC (single extract, so treat as weakly verified). A "Record to Camtasia" open-in option was added in 2025.3.0, and a preset that opens recordings in Camtasia Editor in 2026.2.0. [S-CAP-11, S-CAP-10] DOC
- Capture window menus (File / Edit / View / Help), the reset control, the Open Editor button, and the shortcut text on the Capture button: **no extract described these**. What is known: File > Capture Preferences, File > Import Presets, File > Export All Presets, View > Show/Hide Capture Widget (older), and the global-hotkey field shown in the Capture window. [S-CAP-06, S-CAP-21, S-CAP-18, S-CAP-07] DOC for the listed items; everything else UNVERIFIED.

### Scrolling (formerly Panoramic)
- Snagit supports scrolling capture "vertically and horizontally". [S-CAP-15] DOC
- Two methods:
  - **Automatic Scrolling Capture**: arrows appear when Snagit detects it can auto-scroll. Clicking an arrow captures the horizontal area, the vertical area, or the entire scrolling area.
  - **Manual Scrolling Capture** (formerly "Panoramic"): you scroll yourself and Snagit records what appears inside the selection, then you click **Done**.
  [S-CAP-05, S-CAP-27] DOC
- A "Scrolling Capture" preset ships by default, and a custom hotkey can be assigned to it. [S-CAP-05] DOC
- Advice: scroll one direction at a time, no "zigzag". Prefer the scroll bars to the wheel, to avoid capturing hover states. [S-CAP-05, S-CAP-13] DOC
- **Documented limitations:**
  - Parallax websites may not capture accurately. [S-CAP-13] DOC
  - Third-party utilities, unsupported browsers/apps, drivers and security software can block auto-scroll. Kaspersky Internet Security "may potentially completely break the window detection"; the only known fix is closing its process, because an exception "usually does not work". [S-CAP-13] DOC
  - Pages with multiple scroll areas may defeat detection; use manual (Panoramic) instead. [S-CAP-13] DOC
  - PDF readers: auto-scroll does not work (scroll bars are not detected); opening the PDF in Chrome or Firefox may work. [S-CAP-13] DOC
  - Excel: no automatic scrolling of a worksheet pane or of Print Preview; use manual scrolling or copy the cells. [S-CAP-16] DOC
  - Keep app zoom at 100%, exclude the scroll bar from the selection, and disable floating toolbars. [S-CAP-13] DOC
  - The scrolling preview and control bar could be captured in older versions. This was fixed in 2024.1.0+ via the preference "Hide Snagit during capture and remove Snagit controls from completed captures", for Windows 10 20H1 and newer. [S-CAP-14, S-CAP-12] DOC
  - The Mac App Store build lacks full scrolling capture (Mac only; noted for completeness). [S-CAP-15 extract] DOC
- 2026 scrolling fixes:
  - Crash when stopping a manual scrolling capture (2026.3.0).
  - Crash with a very small scrolling selection (2026.2.0).
  - Manual scrolling freeze or crash on some VMs (2026.1.0).
  [S-CAP-10] DOC

## 2. Presets
- Create: configure the capture, open the **Add Preset** dropdown, and create a new preset from the current settings. [S-CAP-09] DOC
- Per-preset hotkey: click **Add Hotkey** (Windows) and press the key combination. A hotkey lets you capture without opening the Capture window. [S-CAP-09] DOC
- Export a single preset: Presets button, then the properties icon next to the preset, then **Export**. The file extension is **.snagpresets**. [S-CAP-09] DOC
- Export all: **File > Export All Presets**. Import: **File > Import Presets** (Ctrl+click selects several). [S-CAP-21, S-CAP-09] DOC
- Snagit 11/12 called presets "profiles". [S-CAP-32] DOC (historical)

## 3. Global hotkeys and capture keyboard shortcuts (Windows)
- Default global capture: **Print Screen**. It works whenever Snagit runs in the background, and it uses the Capture window's current settings. [S-CAP-07, S-CAP-08, S-CAP-28] DOC
- Windows 11 may route Print Screen to the Snipping Tool; turn off the Windows Keyboard setting to fix it. The Hotkeys tab has an option letting Snagit override other hotkey assignments. [S-CAP-07, S-CAP-19] DOC
- Hotkeys are edited at **File > Capture Preferences > Hotkeys tab**, which has **Restore Defaults**. [S-CAP-07] DOC
- Shortcuts during capture or recording (current Hotkeys Guide, per extract): [S-CAP-07] DOC
  - Enter = capture
  - Shift+Enter = start region selection
  - Esc = cancel
  - F1 = capture help
  - Ctrl+Shift+X = exit Snagit Capture
  - M = show/hide magnifier
  - Arrow keys = move crosshairs 1 px
  - Shift+F9 = start/pause/resume recording
  - Shift+F10 = stop recording
- TechSmith notes the shortcuts were tested on a QWERTY layout. [S-CAP-07] DOC
- **Repeat Last Capture**: the current guide gives no Windows default; you assign it in the Hotkeys tab. Older guides list **Ctrl+Shift+R**. [S-CAP-07, S-CAP-33] Whether Ctrl+Shift+R is the current default is UNVERIFIED.
- The current table has no dedicated fullscreen or window hotkey on Windows; these are selection options. [S-CAP-07] DOC (absence is per extract)
- 2026.4.0 fixed "a crash that could occur when using capture hotkeys in specific circumstances". [S-CAP-10] DOC

## 4. Capture widget (formerly OneClick)
- Current: Capture Preferences > **General** tab lets you choose between the Capture Window and the **Capture Widget**. The widget offers "limited options from a tab anchored to the edge of the screen". "Hover over the blue bar to display the Widget". "Drag the Widget to reposition along the top or side of the screen." [S-CAP-06] DOC
- Older support article: **View > Show Capture Widget / Hide Capture Widget**. [S-CAP-18] DOC. Whether these menu items still exist in 2026 is UNVERIFIED.
- The extract also lists a "Show Capture Widget" checkbox under Editor Preferences > General. [S-CAP-06] DOC. This conflicts with Capture Preferences being the place to choose, so its current placement is UNVERIFIED.
- Historical behaviour:
  - Snagit 11.4/12: OneClick docks along the left, right or top edge.
  - Snagit 10: an orange bar marks the hidden edge, plus an option to make it "completely disappear" when hidden, and timing/animation settings.
  - Snagit 13.1: enabled with File > Capture Preferences > General > "Show OneClick".
  - 2018: "hover the cursor over the blur bar".
  [S-CAP-32, S-CAP-31, S-CAP-30] DOC (historical)
- No official extract found for these widget behaviours: an auto-hide toggle, click-vs-hover choice, always-on-top, multi-monitor behaviour, or bottom-edge docking. UNVERIFIED. INFER: the widget appears only on top and side edges (no bottom edge), based on "top or side".
- 2025.1.1 fixed the widget "would not appear or capture as expected". [S-CAP-11] DOC (single extract)

## 5. Preferences / settings

**Capture Preferences** (Capture window > File > Capture Preferences) [S-CAP-06] DOC

General tab:
- "Run Snagit when Windows starts".
- Theme: "Select Light or Dark from the dropdown to choose the Snagit interface color theme. Or select System for Snagit to automatically follow the color mode set in the Windows system settings." System was added in 2026.2.0. [S-CAP-10]
- "Automatically check for updates", plus a choice of Standard or Delayed updates.
- Capture Window vs Capture Widget.

Capture tab:
- "Hide Snagit during capture and remove Snagit controls from completed captures". This hides the Capture Window and Editor when a capture starts, and removes toolbars and previews from images and videos.
- "Show magnifier" (for pixel accuracy; M toggles it during capture).
- Video countdown option (per older help) and other video options.

Hotkeys tab: described in section 3.

**Editor Preferences** (Editor > Edit > Editor Preferences) [S-CAP-06] DOC

General tab:
- "Data & Privacy" section with the choices "Send usage data", "Send anonymous usage data", or none. In-app help and notifications need one of the first two.

Advanced tab:
- Keep Editor running in the background.
- Delete cropped content.
- Drag-and-drop file type.
- **Reset to Default Settings** (resets all settings).

Library tab:
- Images are stored as **.snagx** and videos as **.mp4**.
- Default location: `C:\Users\username\Documents\Snagit`.
- "Choose location" changes the folder.
- "Import Backup" imports .snagarchive files from 2021 or earlier.
- Older help listed an AppData library path (conflicting, historical).
- Source for the Library tab: S-CAP-06; support article 203731768 for backup and restore.

Other settings sources:
- 2024.2.0 added a product-update check in the Editor Account dropdown. [S-CAP-12] DOC
- No full in-app settings export was found. IT administrators can run `SnagitCapture.exe /e` (Snagit closed, admin prompt) to export a registry file "such as presets, appearance settings, and hotkeys". The Deployment Tool also sets defaults. [S-CAP-23, S-CAP-22] DOC
- Default save location and format: there is no global "default save format" preference in the extracts. Saving is per-preset via Share > File plus the gear options, and captures auto-save to the Library. [support 203731148, S-CAP-06] INFER
- Capture sounds and tray-icon settings: not found in any extract. UNVERIFIED.

## 6. Accessibility (VPAT)
- Snagit 2025 VPAT 2.5 International Edition [S-CAP-24], per search extract only:
  - Dated 15 Mar 2025 and covers the Windows version.
  - Scope: WCAG 2.0, 2.1 and 2.2 at Level AA, plus Revised Section 508.
  - Internal evaluation with NVDA, Narrator and Color Contrast Analyzer.
  - "Without vision" is rated **Does Not Support**. Reasons given: weak Editor toolbar tabbing and missing programmatic names on some capture buttons.
  - Object information and notifications exposed to assistive technology: **Does Not Support**.
  - Low vision: partial. It works with monitor DPI and dark-theme contrast, but responds poorly to OS text zoom and high-contrast mode.
  - Focus is generally visible, with some double-focus issues.
  - DOC (unread PDF; summary only)
- Earlier VPATs exist for 2024 (VPAT 2.5), 2022, 2021 and 2020. [S-CAP-25 and the search list] DOC (existence)
- 2026.3.0 refreshed Capture and Editor colours and icons "for accessibility". [S-CAP-10] DOC
- No 2026 VPAT was found. UNVERIFIED.
