Release candidate 5 (in testing)

Windows test build for invited testers

Test packages of SnapForge 1.0.0-rc.5 are produced automatically by the project's continuous integration (CI) on GitHub. They are not a release:

  • They are GitHub Actions artifacts of the CI run. Downloading them needs a GitHub sign-in.
  • Sign-in is not owner-only access. The repository is public, so anyone with a free GitHub account can download these artifacts. Treat them as public test files.
  • They expire (normally after 30 days) and are then gone.
  • They are not code-signed and have not been approved for general use.
  • Nothing is hosted on this website: it only links to the CI package.

Before you test a build

  • Back up anything important first. Release candidates can still have bugs. If you already use SnapForge, make a Library backup in Settings or copy %LOCALAPPDATA%\SnapForge somewhere safe.
  • Only run a build you obtained from the project's CI run page (or, later, its GitHub Release) and whose checksum you have verified. If you are unsure, wait for the signed release.

System requirements

  • Windows 11, version 24H2 or later, 64-bit (x64). This is the only supported platform.
  • Windows 10, Windows on Arm and other operating systems are not supported and are not tested.
  • No separate .NET installation is needed: SnapForge includes the runtime it uses.
  • Screen recording uses Windows' Media Foundation; Windows “N” editions need Microsoft's Media Feature Pack. Camera recording needs a camera that Windows recognises.

What is in the download

SnapForge comes in two forms with the same version and the same application:

  • Installer (SnapForge-<version>-win-x64-setup.exe) — installs for all users of the PC.
  • Portable ZIP (SnapForge-<version>-win-x64-portable.zip) — no installation; contains SHA256SUMS.txt with a checksum for every file in it.

The exact contents of each release package (for example the license, third-party notices and a checksum list) will be listed here once a release has been published and verified. Nothing is promised until then.

Installing

With the installer

  1. Check the installer's SHA-256 checksum first.
  2. Run SnapForge-<version>-win-x64-setup.exe. SnapForge installs for all users into Program Files, so Windows asks for administrator approval (User Account Control) once for the installation — and once more if you uninstall.
  3. SnapForge itself runs without administrator rights. Start it from the Start menu.

With the portable ZIP

  1. Check the ZIP's SHA-256 checksum first.
  2. Right-click the ZIP, choose Extract All…, and pick a folder you own, for example Documents\SnapForge. No administrator rights are needed.
  3. Open the folder and run SnapForge.exe. Keep the other files in the folder next to it.

When SnapForge starts with Windows, it opens only its notification-area icon and QuickDock — no window.

Verifying the download

Before you run anything, compare its SHA-256 checksum with the published one. In PowerShell, in the folder containing the download:

Get-FileHash .\SnapForge-<version>-win-x64-setup.exe -Algorithm SHA256
Get-FileHash .\SnapForge-<version>-win-x64-portable.zip -Algorithm SHA256
  1. The Hash it prints must match exactly (letter case does not matter) the line for that file in the SHA256SUMS.txt that comes with the packages — for a test build, the one in the same CI artifact; for a release, the checksum shown on this page and on the GitHub Release.
  2. For the portable ZIP, after extracting, you can also check each file against the SHA256SUMS.txt inside the ZIP: Get-FileHash .\SnapForge.exe -Algorithm SHA256.
  3. If any checksum differs, do not run the file; delete it and tell us.

Windows security prompts

Test builds are not code-signed. Windows SmartScreen will probably warn that it “prevented an unrecognized app from starting”, and Smart App Control may block an unsigned build altogether. A future signed release may still show a warning at first, because SmartScreen also relies on reputation built up over time.

  • Keep Microsoft Defender, SmartScreen and Smart App Control turned on. This site will never ask you to turn them off.
  • Only run builds you obtained from the project's CI page and whose checksum you verified. If you are unsure, wait for the signed release.
  • If Defender reports the file, do not run it — please report it.

Uninstalling

Uninstalling keeps your captures. They live in your own Windows profile, %LOCALAPPDATA%\SnapForge (or the Library folder you chose), not in the program folder.

  1. If you turned on Launch SnapForge when I sign in to Windows, turn it off in SnapForge's Settings (or in Windows Settings → Apps → Startup).
  2. Exit SnapForge from its notification-area icon.
  3. Installer: Windows Settings → Apps → Installed apps → SnapForge → Uninstall (asks for administrator approval). Portable: delete the folder you extracted it to.
  4. To remove your captures and settings as well, delete %LOCALAPPDATA%\SnapForge (paste it into the File Explorer address bar). If you moved the Library to another folder, delete that folder too. This permanently deletes your captures, recordings and backups stored there.
